# PhysioMap • ActivForce

Site simples para importar PDFs do ActivForce, extrair força máxima bilateral, calcular assimetria e destacar o lado mais fraco em um mapa corporal.

## Faixas de assimetria
- Verde: até 10%
- Amarelo: acima de 10% até 20%
- Vermelho: acima de 20%

A publicação está preparada para GitHub Pages por meio do workflow em `.github/workflows/pages.yml`.
